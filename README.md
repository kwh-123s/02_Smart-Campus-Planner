# 📚 Smart Campus Planner

대학생을 위한 아주 가벼운 **할 일(투두) 관리 웹앱**입니다.
학과 과제, 동아리 활동, 개인 일정을 한 화면에서 관리할 수 있도록 만들었습니다.

별도의 설치나 회원가입 없이, 웹 브라우저만 있으면 바로 사용할 수 있습니다.

---

## 🎯 프로젝트를 만든 목적

대학생은 하루에도 학과 과제, 동아리 회의·행사, 개인 약속처럼 성격이 다른 할 일을 동시에 관리해야 합니다.
하지만 이런 할 일들을 메모 앱, 캘린더, 메신저 등 여러 곳에 흩어서 관리하다 보면 마감일을 놓치거나 무엇이 더 급한 일인지 헷갈리기 쉽습니다.

**Smart Campus Planner**는 이런 문제를 해결하기 위해 만들어졌습니다.

- 학과 / 동아리 / 개인 할 일을 **하나의 화면**에서 관리
- 할 일마다 **중요도**와 **마감일**을 지정해 우선순위를 한눈에 파악
- **전체 완료율**을 확인하며 진행 상황을 점검
- 로그인 없이도 브라우저에 데이터를 저장해, 새로고침해도 입력한 내용이 사라지지 않음

자세한 기획 배경은 [`PRD.md`](./PRD.md) 문서에 정리되어 있습니다.

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| ✅ 할 일 추가 | 제목을 입력하고 "추가" 버튼을 누르면 새 할 일이 목록에 등록됩니다. |
| 🏷️ 카테고리 설정 | 할 일을 **학과 / 동아리 / 개인** 중 하나로 분류할 수 있습니다. |
| ⭐ 중요도 설정 | 할 일의 중요도를 **상 / 중 / 하** 세 단계로 지정할 수 있습니다. |
| 📅 시작일·마감일 지정 | 할 일을 시작할 날짜와 끝내야 할 날짜(마감일)를 함께 지정할 수 있습니다. 마감일이 지나면 목록에서 "지남" 표시가 함께 보입니다. |
| ☑️ 완료 체크 | 체크박스를 눌러 할 일을 완료/미완료로 전환할 수 있습니다. 완료된 할 일은 취소선과 초록색으로 구분되어 보입니다. |
| 🗑️ 삭제 | 더 이상 필요 없는 할 일은 "삭제" 버튼으로 목록에서 제거할 수 있습니다. |
| 📊 전체 완료율 표시 | 전체 할 일 중 몇 %를 완료했는지 진행률 바(progress bar)와 숫자로 실시간으로 보여줍니다. |
| 💾 새로고침해도 유지되는 저장 | 추가/체크/삭제 결과가 브라우저에 자동 저장되어, 새로고침하거나 창을 다시 열어도 데이터가 그대로 남아있습니다. |

> 이 앱은 로그인/회원가입 기능이 없으며, 여러 기기 간 데이터 동기화도 지원하지 않습니다. (하나의 브라우저 안에서만 데이터가 유지됩니다.) 자세한 범위는 [`PRD.md`](./PRD.md)의 "MVP 범위"를 참고하세요.

## 🚀 사용 방법

이 앱은 별도의 서버나 설치 과정 없이, 웹 브라우저만 있으면 바로 사용할 수 있습니다.

### 방법 1. 내 컴퓨터에서 바로 열어보기
1. 이 프로젝트 폴더를 내 컴퓨터에 다운로드(또는 복제)합니다.
2. 폴더 안의 **`index.html`** 파일을 더블클릭합니다.
3. 기본 웹 브라우저(크롬, 엣지 등)에서 앱 화면이 열립니다.

### 방법 2. 배포된 웹사이트로 바로 접속하기 (GitHub Pages)
아래 링크에 접속하면 설치 없이 바로 앱을 사용할 수 있습니다.

> 🔗 **실행 링크(GitHub Pages)**: `여기에 GitHub Pages 배포 URL을 입력하세요` (예: `https://사용자아이디.github.io/저장소이름/`)

### 앱 사용 순서
1. 상단 입력창에 할 일 제목을 입력합니다.
2. 카테고리(학과/동아리/개인), 중요도(상/중/하), 시작일, 마감일을 필요에 따라 선택합니다.
3. "추가" 버튼을 누르면 목록에 할 일이 등록됩니다.
4. 할 일을 완료하면 체크박스를 눌러 체크 표시를 합니다.
5. 필요 없는 할 일은 "삭제" 버튼으로 지울 수 있습니다.
6. 화면 상단의 "전체 완료율"에서 지금까지의 진행 상황을 확인할 수 있습니다.
7. 브라우저를 새로고침하거나 다시 열어도 입력했던 내용이 그대로 남아있습니다.

## 🛠️ 사용한 기술

이 프로젝트는 별도의 설치나 빌드 과정 없이 바로 실행되는 **순수 웹 기술(Vanilla Web)** 로만 만들어졌습니다.

- **HTML5** — 화면 구조 (`index.html`)
- **CSS3** — 화면 디자인 및 반응형 레이아웃 (`style.css`)
- **JavaScript (Vanilla JS, ES6+)** — 할 일 추가/완료/삭제, 완료율 계산 등 동작 로직 (`script.js`)
- **Web Storage API (`localStorage`)** — 새로고침해도 데이터가 사라지지 않도록 브라우저에 저장하는 기능

별도의 프레임워크(React, Vue 등)나 서버, 데이터베이스는 사용하지 않았습니다. 그래서 프로젝트 폴더를 내려받아 `index.html` 파일만 열어도 바로 동작합니다.

## 📁 프로젝트 파일 구성

```
02_Smart Campus Planner/
├── index.html      # 화면 구조 (입력 폼, 할 일 목록, 완료율 영역)
├── style.css       # 화면 디자인 (색상, 배지, 레이아웃 등)
├── script.js       # 동작 로직 (추가/완료/삭제, 완료율 계산, 저장·불러오기)
├── PRD.md          # 프로젝트 목적, 대상 사용자, 요구사항, MVP 범위 정의 문서
├── TASKS.md        # 3단계(T1~T3)로 나눈 구현 작업 계획 문서
├── PROMPTS.md      # 각 단계를 구현할 때 사용한 요청 프롬프트 모음
└── README.md       # 지금 보고 있는 프로젝트 소개 문서
```

| 파일 | 역할 |
|---|---|
| `index.html` | 웹앱의 뼈대가 되는 화면 구조(입력창, 버튼, 목록, 완료율 표시 영역)를 정의합니다. |
| `style.css` | 버튼, 배지, 진행률 바 등 화면을 보기 좋게 꾸미는 디자인을 담당합니다. |
| `script.js` | 할 일을 추가·완료 체크·삭제하고, 완료율을 계산하며, `localStorage`에 데이터를 저장/불러오는 실제 동작을 담당합니다. |
| `PRD.md` | 이 앱을 왜 만들었는지, 누구를 위한 것인지, 무엇을 만들어야 하는지(MVP 범위)를 정리한 기획 문서입니다. |
| `TASKS.md` | PRD를 바탕으로 구현을 3단계(T1: 기본 뼈대 → T2: 분류·완료율 → T3: 저장 기능)로 나눈 작업 계획서입니다. |
| `PROMPTS.md` | TASKS.md의 각 단계를 실제로 구현할 때 AI에게 전달한 요청 프롬프트 모음입니다. |

## 📌 참고

- 이 앱은 브라우저의 `localStorage`에 데이터를 저장하므로, **같은 브라우저 + 같은 주소**로 접속했을 때만 저장된 할 일이 유지됩니다. (다른 브라우저나 다른 기기에서는 데이터가 공유되지 않습니다.)
- 프로젝트의 기획부터 구현까지의 전체 흐름이 궁금하다면 `PRD.md` → `TASKS.md` → `PROMPTS.md` 순서로 읽어보시길 추천합니다.
